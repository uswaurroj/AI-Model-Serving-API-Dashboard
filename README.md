# AI Model Serving API & Interactive UI Dashboard

A full-stack applied AI platform demonstrating real-time model inference, RESTful API endpoints, JSON payload serialization, and an interactive browser-based dashboard.

## System Architecture
- **Backend API Engine:** Python HTTP/REST API server handling dynamic endpoints (`/api/predict`, `/api/health`).
- **Data Exchange Format:** Structured JSON payloads for inference request/response cycles.
- **Frontend UI Dashboard:** Interactive web dashboard with real-time model evaluation and dynamic input parameters.
